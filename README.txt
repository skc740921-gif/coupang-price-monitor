쿠팡 경쟁가격 모니터 v4 - Render용 올인원 서버

구성
- 모바일 웹 화면
- Node.js 서버
- Chromium으로 쿠팡 검색결과 실제 조회 시도
- 상품별 가격 비교 및 이전 가격 로컬 저장

배포 방식
1. 이 폴더를 GitHub 저장소에 업로드
2. Render에서 New > Web Service
3. GitHub 저장소 연결
4. Runtime: Docker
5. 배포

주의
쿠팡이 클라우드 서버의 자동접속을 차단할 수 있습니다.
차단될 경우 화면에 '쿠팡이 서버의 자동 접속을 차단했습니다.'라고 표시됩니다.
